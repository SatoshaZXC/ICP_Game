# ICP Game

## 📖 Опис
**Консольна рольова гра в стилі dark fantasy** на C#.
## ✨ Основні можливості

- 🧙 **Система персонажа** — створення, характеристики, прогрес
- 🎒 **Інвентар** з підтримкою різних типів предметів

  <img width="567" height="163" alt="image" src="https://github.com/user-attachments/assets/c1b487be-9c92-460d-a92c-c4a6a506b203" />
  
- ⚔️ **Екіпірування** — зброя, магічні предмети, артефакти

  <img width="382" height="314" alt="image" src="https://github.com/user-attachments/assets/ddb86ad1-62b8-4a9c-8639-949cbe31202e" />
  
- 🗃️ **Контейнери** — скрині, лут, випадкові події

 <img width="401" height="108" alt="image" src="https://github.com/user-attachments/assets/1dcb4295-39c6-4489-a80c-2be29bd67181" />
  
- 🎲 **Coin Flip** — механіка ризику та винагороди
- 📍 **Сцени** — розміщення об'єктів у світі
- 🧪 **Повне тестування** — xUnit + Assert

### Типи предметів
- `Weapon` — звичайна зброя
- `MagicalWeapon` — магічна зброя з ефектами
- `Consumable` — зілля, їжа, свитки
- `Artifact` — рідкісні потужні предмети

# Contributing to ICP_Game

Дякуємо за інтерес до проєкту ICP_Game!

Цей файл описує порядок роботи з проєктом для сторонніх розробників.

---

## 🚀 Як запустити проєкт

### 1. Клонувати репозиторій
```bash
git clone https://github.com/SatoshaZXC/ICP_Game.git
```
### 1. Перейти в директорію проєкту
```bash
cd ICP_Game
```
### 3. Відкрити рішення

Відкрити файл:
```bash
ICP_Game.sln
```
або через IDE (Visual Studio / Rider)

### 🛠️ Збірка проєкту
```bash
dotnet build
```
### 🎮 Запуск застосунку
```bash
dotnet run --project ICP
```
### 🧪 Запуск тестів
```bash
dotnet test
```
# Тести використовують xUnit і перевіряють:

- логіку гравця
- інвентар
- механіку CoinFlip

  
# 📁 Структура проєкту

- ICP — основна логіка гри
- ICP.Entity — ігрові сутності (Player, Item, Inventory)
- ICP.Tests — unit тести (xUnit)
  
# 🧠 Правила внесення змін

- нові фічі створювати в окремих гілках
- кожна логіка повинна мати тести
- не пушити код, який не збирається
- логіку не змішувати з Console UI
# 🧪 Тестування

- використовувати xUnit
- під час створення класу для тестування надайте йому назву, що відповідає об’єкту тестування
### 📌 Приміткa:

Проєкт створений як навчальний, тому архітектура може змінюватися.
